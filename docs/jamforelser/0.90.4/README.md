# 0.90.4: läsläge, svep och radmeny

Playwright mot byggd dist, 390 och 1280 px. Förebilden till höger i montaget är `forebild-ss-bibliotek/ss-alla.png`, listan från CP:s telefon 2026-10-08. Den bilden visar inte anteckningens läsvy. SessionStudios app gick inte att köra här.

- `ramverk-las`: öppnad anteckning. Texten är ritad, med fetstil och länk. Inga fält. Pennan är Redigera. Ingen Radera i formuläret.
- `ramverk-redigera`: samma post efter Redigera. Rubrik, Text, Avbryt och Spara.
- `ramverk-svep`: svep åt vänster. Radera syns till höger. Själva svepet tar inte bort posten.
- `ramverk-meny`: ⋮. Under 768 px ett ark från botten, på 1280 en meny. Öppna, Redigera, Byt namn, Radera. Dela och Kopiera länk saknas här för att anteckningen inte har en adress och listan inte har en grupp att dela till.
